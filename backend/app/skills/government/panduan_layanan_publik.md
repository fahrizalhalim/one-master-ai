# Skill: Panduan Penggunaan Situs/Layanan Publik (Situs Desa, Portal Kampus, Dinas)
Kata kunci: panduan situs, situs desa, panduan website, cara pakai situs, panduan layanan, brosur cara pakai.

## Peran
Om AI menyusun PANDUAN PENGGUNAAN situs/layanan publik untuk orang awam (warga desa, mahasiswa, pemakai layanan dinas) — dalam bentuk PDF siap edar atau gambar/brosur. Bahasa awam, kalimat pendek, tabel, emoji di versi chat.

## Prosedur
1. **Cek situs aktual dulu** (curl/nslookup URL, tes www & non-www). Jika aktif → ekstrak menu asli (grep title & item menu). Jika TIDAK aktif (DNS belum terdaftar/situs mati) → gunakan struktur standar layanan publik Indonesia dan CATAT EKSPLISIT di panduan bahwa situs belum aktif + minta screenshot menu setelah aktif untuk penyesuaian.
2. **Struktur panduan 6 bagian**:
   - (1) Cara membuka/akses: langkah bernomor + tip 'Tambahkan ke Layar Utama' (PWA) + 'hemat kuota, tanpa aplikasi tambahan'.
   - (2) Menu/fitur & fungsinya: tabel [Menu | Apa isinya | Untuk siapa].
   - (3) Panduan PENGGUNA awam: 5 kebiasaan rutin yang perlu dilakukan (baca berita rutin, cek transparansi, cek syarat layanan sebelum datang, laporkan informasi salah, sebarkan tautan).
   - (4) Panduan PENGELOLA: tabel [Tugas rutin | Frekuensi | Catatan] — unggah konten, perbarui data wajib, jawab pesan maks 2×24 jam, ganti password admin tiap 3–6 bulan, 1 orang pegang password.
   - (5) Dasar hukum singkat yang relevan (situs desa: UU 14/2008 KIP; Permendagri 90/2019; Permendagri 20/2018 APBDes wajib publikasi; portal kampus: PPE/PEDOMI; layanan dinas: UU PDP 27/2022 untuk data pribadi).
   - (6) FAQ 5–6 pertanyaan umum dijawab bahasa awam.
3. **Keamanan selalu disertakan**: jangan kirim KTP/KK via situs umum; urusan berkas pribadi datang langsung ke kantor; jangan bagikan password admin via grup WhatsApp.
4. **Format PDF**: reportlab — hero berwarna tema (desa = hijau), tabel, box checklist, footer dasar hukum + tanggal versi + catatan penyesuaian bila situs belum aktif.
5. **Versi gambar/brosur**: HTML 1080px → screenshot full-page → verifikasi visual → kirim PNG. Samarkan identitas pribadi bila dokumen memuat nama/NPM.
6. **Etika & batas**: panduan ini bersifat edukatif; bila situs milik pihak ketiga, sebut 'sesuaikan dengan menu asli situs' — jangan mengklaim fitur yang tidak dikonfirmasi.
